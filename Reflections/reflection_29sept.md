## Basic Shapes in Computer Graphics

In the current Computer Graphics class, we discussed how graphical objects can be created using basic geometric shapes. The discussion helped me understand that computer graphics is based on simple shapes and their properties, which can be combined to create more complex graphical objects.

One of the interesting discussions was about how a particular graphical object could be represented. Different ideas were discussed in the class. For example, one suggestion was to create a circle, while another suggestion was to create a line whose starting point and ending point are the same. This made me realize that there can be different approaches to represent or create a graphical object depending on the required output.

This discussion also made me think about how graphics programming is connected to geometry. Before creating an object through code, we need to understand what the object looks like mathematically and what information is required to represent it on the screen.

## Representing Objects Using Lines and Circles

We discussed how simple graphical primitives such as lines and circles can be used to construct or represent objects. A circle can be defined using its centre and radius, while a line can be defined using two points.

The discussion about using a line with the same starting and ending point was particularly useful because it showed how the properties of graphical primitives affect what we see on the screen. It also helped me understand that the visual appearance of an object depends not only on the primitive itself but also on its coordinates and other properties.

This gave me a better understanding of how a computer represents something that we visually recognize as a shape. The computer does not simply understand the object as a picture; it uses coordinates, dimensions, and graphical instructions to construct it.

## Lines and Starting and Ending Points

Another important part of the discussion was about lines. A line is represented using a starting point and an ending point. These points determine the position, direction, and length of the line.

For example, changing the x or y coordinate of either point can change the direction or position of the line. Therefore, coordinates play an important role in controlling graphical objects.

We also discussed what happens when the starting and ending points are modified. If the two points are different, a visible line is produced between them. If the two points are made the same, the result changes because there is no distance between the two points.

This helped me connect the mathematical idea of points and distance with their practical use in computer graphics.

## Line Thickness and Graphical Properties

We also discussed the thickness of a line and how it can be changed. A line does not only have a position and length; it can also have different graphical properties that control its appearance.

The thickness of a line can be increased or decreased depending on how we want it to appear on the screen. This can be useful when a line needs to be more visible or when different parts of a graphical design need to have different visual importance.

This discussion made me understand that drawing an object is only one part of computer graphics. We can also modify its appearance through different properties such as thickness, size, position, and dimensions.

## 2D Shapes and Coordinates

Another major topic discussed in class was drawing 2D shapes. We discussed how shapes such as circles, rectangles, lines, and other geometric objects can be created using coordinates.

In a 2D graphics environment, the x-axis and y-axis are used to specify the position of an object. The coordinates determine where the object will appear on the screen. Along with position, different measurements such as width, height, radius, and thickness can be used to define the shape.

For example, a rectangle can be represented using its starting position, width, and height, whereas a circle can be represented using its centre and radius. Therefore, different shapes require different types of information to describe them.

## Logic Behind Drawing Graphical Objects

The discussion also helped me understand the importance of logic before coding. Before drawing a shape, we need to think about what exactly we want to draw and what information is required to create it.

For example, if we want to draw a line, we need to decide its starting and ending points. If we want to draw a circle, we need to decide its centre and radius. If we want to change the appearance of a line, we may also need to consider its thickness.

Therefore, the process of creating graphics involves more than simply writing a drawing command. We first need to understand the object, break it down into its basic properties, and then convert that understanding into code.

## Connection Between Mathematics and Graphics

Today’s discussion also helped me understand the connection between mathematics and computer graphics. Concepts such as points, coordinates, distance, shapes, and dimensions are directly used when creating graphical objects.

A graphical object can therefore be viewed both visually and mathematically. What we see as a shape on the screen is represented internally using numerical values and geometric relationships.

This connection is important because changing a single coordinate or property can change the complete appearance or position of an object.
